# 🤖 Universal AI Utility — Prompt Engineering

A modular AI-powered utility application built using **Python, Streamlit, OpenAI API, and Prompt Engineering**.

This project combines multiple AI-powered tasks into a single user-friendly application. The user selects a task, enters the required input, and the application dynamically creates a suitable prompt and sends it to an OpenAI model.

---

## 📌 Project Overview

The **Universal AI Utility** is designed to demonstrate how **one AI application can perform multiple tasks using prompt routing**.

Instead of creating separate applications for every task, this project uses a single Streamlit interface with different task-specific prompts.
